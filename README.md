# Calculadora em C

## Sobre o projeto

Este projeto consiste em uma calculadora desenvolvida na linguagem C, criada para praticar conceitos de programação e versionamento com Git e GitHub.

## Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão

## Tecnologias utilizadas

- Linguagem C
- Git
- GitHub

## Objetivo

Este repositório foi criado para aplicar os conhecimentos adquiridos na trilha GitHub Foundations, incluindo criação de repositórios, commits, branches e pull requests.
